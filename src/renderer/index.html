About this app and how you can support the development

𝄢 BASSS

Broadcast App and Server for SoundTouch Speakers

If this app rescued your Bose SoundTouch speakers and saved you the cost of buying new ones, please consider supporting my work. Your donation keeps this app free from ads, with active development and community support!

BASSS is a lightweight, easy to use, local, and private alternative designed to rescue Bose SoundTouch speakers from the cloud server shutdown.

By bypassing the deprecated official cloud server and running entirely on your local home network, BASSS combines a Node.js/Express local server with an elegant Electron desktop frontend to keep your speakers fully operational. Unlike other smart home servers, BASSS does not need to run 24/7.

The Autonomy: Once configured the speaker resolves the radio stream directly from the web to your speaker without the need of this app. You can safely close the BASSS app.

Cold Boot Recovery: The app is only required if a speaker is completely disconnected from power. When powered back on, it will search for its local configuration. Simply open BASSS for a moment, let the speakers start, and they are fully autonomous once again.

Here is how BASSS delivers an easy-to-use local solution, fully grounded in your speaker’s technical capabilities:

1. The Device-Specific Preset Revolution

In the original Bose cloud architecture, all speakers linked to a user account were forced to share the same six global presets. BASSS changes this completely by binding presets to individual devices.

How it works: When a speaker powers on or asks for its presets, it calls your local server using its unique physical MAC or Device ID.
The Benefit: Instead of returning a global list, this app reads from a local presets.json file and serves custom, room-specific presets (1–6) tailored to each individual speaker. This means your "Kitchen" speaker and your "Living Room" speaker can have entirely different, independent preset lineups.

2. Seamless Radio-Browser Integration

Since official internet radio directory services like TuneIn can fail offline, BASSS integrates with the free, community-driven radio-browser.info database:

Favorites: Users search for worldwide radio stations directly in the app’s Radio Browser tab and save them to Favorites.
Stream Resolution: Within the app, you can easily map any saved favorite to one of the six preset buttons on a specific speaker. When a speaker requests that preset, your SoundTouch speaker queries the radio-browser.info API for the active URL and instantly redirects it to the raw audio stream, no app needed. Easy and stable!

3. Desktop Control and Sync via WebSockets

BASSS acts as a unified desktop control center, utilizing the speaker's built-in local Web Services API. To ensure that your desktop app's UI matches what is actually happening on your physical speakers, BASSS establishes an asynchronous WebSocket connection directly to each speaker.

Instant Updates: Instead of constantly polling the speakers, BASSS listens for server-initiated XML updates. Whenever a user adjusts the volume physically, changes a preset, or a new track starts playing, the speaker pushes a notification (like VolumeChange, PresetsChangedNotifyUI, or NowPlayingChange). The Electron app instantly parses these updates and refreshes your dashboard in real-time.

Modify SoundTouch Speaker

Generate configuration files that point actual Bose speakers to this app.

1

Prepare USB Stick

Bose SoundTouch speakers require an empty file named remote_services on a USB drive to enable Telnet access during reboot.

2

Prepare Bose Speaker and attach USB Stick

💡 Instruction: Unplug the power cable of your Bose SoundTouch speaker, insert the USB stick containing the remote_services file into the USB port on the back of the speaker, and plug the power cable back in. The speaker will reboot with Telnet enabled.

⚠️ Note for SoundTouch 10: The SoundTouch 10 only features a Micro-USB port on the back. To connect a standard USB stick, you must use a Micro-USB adapter that explicitly supports USB-OTG.

3

Select Configuration Endpoints

💡 Tip: IP addresses in local networks can change over time. It is highly recommended to prefer the hostname option (e.g. .local or .fritz.box). You can verify if it is active using the host check indicator on the bottom left.
⚠️ Important for FRITZ!Box users: Make sure to select the hostname ending in .fritz.box.

⚙️ Static IP Fallback: If hostnames are not supported or fail to resolve in your local network, you will need to select the server's raw IP address. In this case, please configure your router (DHCP static lease / "Always assign same IP") so that the computer running the BASSS app always receives the same IP address, preventing connection loss in the future.

4

Perform Speaker Modification

Clicking the button below will automatically generate the required XML configuration file and initiate a connection to copy it to the selected speaker. After rebooting the speaker, it will redirect all registration and stats requests from the speaker to your local server instead of Bose's official cloud.

During this process, a randomly generated accountId is transferred to the speaker's SystemConfigurationDB.xml. To keep everything safe, the original SystemConfigurationDB.xml is backed up on the device itself. All modifications can be reverted!

🛡️ Safe Process: There is no risk of breaking anything. Since the official Bose servers have been discontinued, even a misconfiguration will have no negative impact, and you can repeat this setup at any time.

Kudos to the developers at Bose for leaving this backdoor open, which makes performing this modification quite easy!
